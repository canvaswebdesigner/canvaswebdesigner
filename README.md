# Yusuf — Web Designer

Yerel işletmeler için **mobil uyumlu, hızlı ve dönüşüm odaklı** web siteleri tasarlıyorum. Her projeyi işletmenin çalışma biçimine, müşterisinin karar sürecine ve gerçek iletişim kanallarına göre kurguluyorum.

## Neler yapıyorum

- İşletmeye özel araştırma ve bilgi mimarisi
- Mobil öncelikli UI/UX tasarımı
- WhatsApp, telefon ve yol tarifi odaklı dönüşüm akışları
- Erişilebilirlik, özel 404 sayfası ve responsive kontroller
- GitHub ve Cloudflare üzerinden sürümlü, hızlı yayın
